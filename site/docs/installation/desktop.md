# Desktop

Brigade.app — desktop-клиент Brigade. Сейчас доступна версия для macOS на Apple Silicon.
Приложение может запускать агентов локально или подключаться к удалённому инстансу.

1. [Установите приложение на macOS](macos.md).
2. Выберите окружение:
   - для работы на этом Mac используйте локальное окружение; в **Настройки → Среда агента** выберите Local или Docker;
   - для работы с сервером [добавьте удалённое окружение](../guides/remote-environments.md) и войдите с учётной записью этого инстанса.

В инструкции по удалённым окружениям также описаны проброс портов и подключение
файловой системы сессии через FUSE-T.
