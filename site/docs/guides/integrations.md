# Интеграции

Интеграции связывают Brigade с внешними сервисами, через которые можно ставить задачи
агенту и получать его ответы. Диалог при этом сохраняется в сессии Brigade.

В отличие от [уведомлений](notifications.md), интеграция не только сообщает о событии,
но и принимает сообщения пользователя. Для новых сессий она использует заранее
выбранное [подключение агента](agents.md).

## Telegram

Подключите собственного бота, чтобы общаться с агентом из Telegram. Личные чаты и топики
связываются с сессиями Brigade; бот отвечает только привязанному владельцу.

[Подключение и работа с Telegram](telegram.md).
