# Плагины

Плагин превращает ACP-сессию в предметный workspace: его MCP-сервер даёт агенту
инструменты, а MCP App занимает всю рабочую область. Приложение и полный ACP-чат открываются
в отдельных вкладках, поэтому стандартный чат не ограничивает интерфейс плагина. Приложения
устанавливаются отдельно для каждого пользователя и выбираются при создании сессии.

## Установка

Откройте **Настройки → MCP Apps** и вставьте HTTPS-ссылку на `.mcpb` либо загрузите файл.
Раздел показывает требуемую платформу: для Docker это `linux-amd64`, для local-сессий
Brigade.app — `darwin-arm64`. Несколько сборок одного приложения можно установить
последовательно; при старте сессии Brigade выберет подходящую автоматически.

После разбора manifest заполните появившиеся настройки. Sensitive-поля сохраняются в
пользовательском vault и никогда не возвращаются в браузер.

Оператор может дополнительно установить системное приложение для всех пользователей:

```bash
brigade plugin install ./brigade-cad-linux-amd64.mcpb
brigade plugin list
```

Для Brigade в Docker CLI-команда выполняется внутри серверного контейнера:

```bash
docker exec brigade brigade plugin install \
  https://github.com/grigory51/brigade/releases/latest/download/brigade-cad-linux-amd64.mcpb
```

После установки откройте **Новая сессия** и выберите плитку приложения. Версия
закрепляется за сессией: обновление плагина влияет только на новые сессии.

## Обновление и удаление

Пользовательские приложения обновляются и удаляются в том же разделе настроек. Для
загруженного файла обновление означает повторную загрузку; HTTPS-источник можно скачать
повторно кнопкой обновления. Чтобы одна ссылка всегда вела на свежую версию, используйте
стабильный адрес вроде GitHub Releases `/releases/latest/download/application.mcpb`.
CLI сохраняет команды `plugin update` и `plugin remove` для системных приложений.

Удалить приложение нельзя,
пока существуют использующие его сессии. Каталог `plugins_dir` должен входить в backup
вместе с SQLite: база хранит manifest и закреплённые версии, каталог — исполняемые bundles.

Создание собственного плагина описано в [контракте](../reference/plugin-contract.md).
