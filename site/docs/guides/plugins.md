# Плагины

Плагин добавляет к ACP-сессии предметные инструменты и необязательную панель. Например,
CAD показывает модель и инспектор, а Coder — файлы, Git и результаты. Чат, история,
композер и запросы разрешений всегда остаются в интерфейсе Brigade. MCP App не заменяет
клиент сессии.

На широком экране панель находится справа от чата. На mobile чат и панель располагаются
один под другим. Приложения устанавливаются отдельно для каждого пользователя.

## Установка

Откройте **Настройки → MCP → MCP Apps** и вставьте HTTPS-ссылку на `.mcpb` либо загрузите файл.
Раздел показывает требуемую платформу: для Docker это `linux-amd64`, для local-сессий
Brigade.app — `darwin-arm64`. Несколько сборок одного приложения можно установить
последовательно; при старте сессии Brigade выберет подходящую автоматически.

После разбора manifest заполните появившиеся настройки. Sensitive-поля сохраняются в
пользовательском vault и никогда не возвращаются в браузер.

Оператор может дополнительно установить системное приложение для всех пользователей:

```bash
brigade plugin install ./brigade-cad-linux-amd64.mcpb
brigade plugin list
```

Для Brigade в Docker CLI-команда выполняется внутри серверного контейнера:

```bash
docker exec brigade brigade plugin install \
  https://github.com/grigory51/brigade/releases/latest/download/brigade-cad-linux-amd64.mcpb
```

После установки откройте **Новая сессия**:

1. Выберите тип сессии: **CLI** или **ACP**.
2. Для ACP выберите необязательную панель: **Без панели**, **CAD**, **Coder** или другой
   установленный плагин.
3. Создайте сессию. В ACP-сессии останется штатный чат, а выбранное приложение откроется
   рядом с ним.

Версия плагина закрепляется за сессией: установка новой версии не меняет уже открытые
сессии автоматически.

## Смена панели

Откройте селектор **Панель** в ACP-сессии и выберите приложение или **Без панели**.
Переключение доступно, когда агент не генерирует ответ. Brigade сохраняет разговор,
workspace, контейнер и native session ID, но меняет MCP-сервер и developer instructions
предметной области. Для этого ACP-адаптер переинициализируется с тем же native session ID.

Смена вкладки внутри CAD или Coder — только визуальное действие: она не
переинициализирует адаптер. Во время генерации селектор панели недоступен. Дождитесь
завершения или остановите текущий turn.

## Обновление и удаление

Пользовательские приложения обновляются и удаляются в том же разделе настроек. Для
загруженного файла обновление означает повторную загрузку. У приложения, установленного
по HTTPS, можно изменить URL пакета и сохранить: Brigade заново скачает и проверит bundle.
Чтобы одна ссылка всегда вела на свежую версию, используйте
стабильный адрес вроде GitHub Releases `/releases/latest/download/application.mcpb`.
После установки новой версии нажмите **Обновить** у существующей сессии: Brigade
перезапустит её runtime и применит актуальную установленную версию приложения.
Обновление bundle в настройках и обновление runtime сессии — отдельные действия.
CLI сохраняет команды `plugin update` и `plugin remove` для системных приложений.

Удалить приложение нельзя,
пока существуют использующие его сессии. Каталог `plugins_dir` должен входить в backup
вместе с SQLite: база хранит manifest и закреплённые версии, каталог — исполняемые bundles.

Создание собственного плагина описано в [контракте](../reference/plugin-contract.md).
