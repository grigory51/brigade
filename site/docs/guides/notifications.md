# Уведомления

Уведомления сообщают о результате работы агента, когда вы не следите за открытой
сессией. Brigade отделяет событие от способа доставки: у пользователя может быть
несколько подключений, в том числе несколько подключений одного типа.

Для каждого подключения выбирается свой набор событий:

- **Завершение ответа** (`turn_end`) — агент закончил текущий turn;
- **Ошибка** (`error`) — turn завершился с ошибкой.

Обычная остановка через Stop не отправляет уведомление о завершении. Одно событие
доставляется во все подключения, где оно включено. Уведомления не создают сессии и не
передают ответы пользователя агенту — для двустороннего общения есть [интеграции](integrations.md).

## Подключение транспорта

Сейчас доступен ntfy. Настройки доставки зависят от выбранной реализации.

{% list tabs %}

- ntfy

  1. Откройте **Настройки → Уведомления**.
  2. Нажмите **Добавить → ntfy**.
  3. Укажите название, server (необязательно — используется `https://ntfy.sh`), topic и token для приватного topic.
  4. Выберите события, сохраните и нажмите **Тест**.

  Можно добавить несколько ntfy-подключений с разными topics и наборами событий.
  Token хранится зашифрованным и после сохранения не возвращается в UI.

  Кнопка **Тест** отправляет пробное уведомление независимо от выбранного набора событий.
  Если оно не пришло, проверьте адрес сервера, topic и token.
