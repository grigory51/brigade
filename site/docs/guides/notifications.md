# Уведомления

У пользователя может быть несколько notification backends. Сейчас реализован ntfy.

1. Откройте **Настройки → Уведомления**.
2. Нажмите **Добавить → ntfy**.
3. Укажите название, server (необязательно — используется `https://ntfy.sh`), topic и token для приватного topic.
4. Выберите события, сохраните и нажмите **Тест**.

Можно добавить несколько ntfy-подключений с разными topics и наборами событий. Token хранится зашифрованным и после сохранения не возвращается в UI.
