# MCP и секреты

MCP-серверы принадлежат пользователю и доступны Claude Code и Codex. Brigade поддерживает `stdio`, Streamable HTTP и SSE.

## Добавление сервера

1. Откройте **Настройки → MCP-серверы**.
2. Нажмите **Добавить** и выберите transport.
3. Для `stdio` задайте command, args и env; для HTTP/SSE — URL и headers.
4. Сохраните сервер.
5. Включите его при создании сессии либо в меню **MCP** существующей ACP-сессии и нажмите Save.

Команда `stdio` выполняется внутри среды агента. Если там нет нужного runtime, соберите [пользовательский образ](environment.md).

## Vault

Секреты находятся в том же разделе MCP. Создайте имя и значение, затем используйте ссылку в env или header:

```text
${secret.GITHUB_TOKEN}
```

Значение шифруется в SQLite, никогда не возвращается в браузер и передаётся MCP-процессу в памяти. Удаление секрета не удаляет ссылки на него: сессия с неразрешимой ссылкой не запустится, пока конфиг не будет исправлен.
