# Профили ответов

Профиль добавляет к системным инструкциям сессии требования к стилю ответа, не изменяя исходные сообщения пользователя.

В **Настройки → Профили ответов** доступны:

- **Обычно** — неудаляемый пустой профиль с поведением агента по умолчанию;
- предустановленные **Короткий** и **Подробный** — их можно редактировать или удалить;
- собственные профили.

Профиль выбирается при создании ACP-сессии и меняется в существующей сессии. Используйте инструкции вроде «Сначала дай короткий вывод, подробности только по запросу», а не дублируйте в них рабочую задачу.
