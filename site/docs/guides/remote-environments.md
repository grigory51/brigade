# Удалённые окружения в Brigade.app

Brigade.app может работать с локальным Brigade или подключаться к удалённому инстансу. Выберите окружение при первом запуске или переключите его над списком сессий. Одно окно показывает сессии и настройки только активного окружения.

## Подключение

1. Откройте **Настройки → Окружения**.
2. Добавьте HTTPS-адрес инстанса без пути, например `https://brigade.example.com`.
3. Войдите с учётной записью этого инстанса и выберите окружение.

Интерфейс остаётся локальной частью Brigade.app, а API-запросы уходят через встроенный прокси. Refresh token хранится в macOS Keychain. Удалённый инстанс должен быть доступен с Mac по HTTPS; для loopback-адресов разрешён HTTP.

## Файлы сессии

Установите [FUSE-T](https://www.fuse-t.org/) один раз:

```bash
brew install macos-fuse-t/homebrew-cask/fuse-t
```

В открытой удалённой сессии нажмите **Файлы**. Workspace появится в `~/Brigade/<окружение>/<сессия>--<id>` и будет доступен на чтение и запись. Mount восстанавливается при следующем запуске Brigade.app.

Для Docker-инстанса workspace должен храниться на хосте через `agent_home_dir`; стандартная Docker-конфигурация Brigade уже использует такую раскладку.

## Проброс портов

Нажмите **Порты**, укажите порт внутри сессии и, при необходимости, локальный порт. Brigade.app откроет только `127.0.0.1:<порт>` и построит зашифрованный WebSocket-туннель до среды агента. Пробросы также восстанавливаются при запуске приложения.
