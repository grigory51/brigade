# Встроенные MCP и навыки

Brigade добавляет агенту шесть инструментов MCP-сервера `brigade` и четыре навыка (skills). Инструменты выполняют действия или показывают карточки в чате; навыки содержат инструкции по их использованию и обращениям к API Brigade.

Имя сервера — `brigade`, имя отдельного инструмента — например, `browser`. Клиент может отображать полное имя как `mcp.brigade.browser`, `mcp__brigade__browser` или в другом формате. Ниже приведены имена инструментов без префикса клиента.

## Доступность

| Возможность | Claude CLI | Claude ACP | Codex CLI | Codex ACP |
|---|---|---|---|---|
| Встроенный MCP `brigade` | Не подключается | Подключается | Не подключается | Подключается |
| Навыки `preview` и `note` | При включённом preview | При включённом preview | При включённом preview | При включённом preview |
| Навыки `brigade-ui` и `brigade-files` | Нет | Нет | Нет | Независимо от preview |
| Browser-инструкция в system prompt | Нет | Да | Нет | Да |

Таблица описывает штатную доставку, а не наличие ранее установленных файлов. Подключение MCP требует доступного runtime, установка навыков — доступного для записи workspace. В Docker без персонального home навыки не устанавливаются. Ошибка установки навыка записывается в лог и не прерывает запуск сессии.

В **Docker ACP** MCP доставляется отдельным runtime-слоем для обоих агентов. Штатный базовый образ содержит Chromium и его зависимости; другая база должна предоставлять их отдельно. В **Local ACP** необходим настроенный путь к локальному MCP-серверу: Brigade.app задаёт его из своего комплекта файлов. Сам по себе режим Local не гарантирует наличие встроенного MCP. Для браузера на macOS используется установленный Google Chrome, на Linux требуется Chromium с зависимостями Playwright.

В **CLI** встроенный MCP не подключается, даже если установлены навыки `preview` и `note`. Поэтому наличие `note` не означает доступность карточки `save_note`. Пользовательские MCP-серверы настраиваются отдельно.

Подробнее: [Среда агента](environment.md), [MCP-серверы](mcp.md).

## MCP-инструменты

Параметры без отметки «необязательный» обязательны. У `browser` дополнительные требования зависят от действия.

### `browser`

Браузер сессии с JavaScript и cookies. Предназначен для открытия страниц, чтения текста и взаимодействия с сайтом, в том числе когда обычного HTTP-запроса недостаточно.

| Параметр | Тип | Назначение |
|---|---|---|
| `action` | string | `open`, `read`, `click`, `fill`, `press` или `close` |
| `url` | string | URL страницы; обязателен для `open` |
| `proxy` | string | Необязательный HTTP(S) proxy для `open` |
| `selector` | string | Playwright locator selector; обязателен для `click` и `fill`, до 2000 символов |
| `text` | string | Значение для `fill`, до 16000 символов; пустая строка разрешена |
| `key` | string | Клавиша или сочетание для `press`, до 100 символов |

`open` открывает URL; `read` читает страницу; `click`, `fill` и `press` выполняют действие и возвращают обновлённый текст. Для чтения и взаимодействия нужна открытая страница. Результат включает статус, URL, заголовок и до 20000 символов `body.innerText`. Query-параметры и fragment удаляются из возвращаемого URL. Cookies, storage и значения password-полей не включаются автоматически в результат; это не исключает чувствительных данных в самом тексте страницы.

URL страницы и proxy допускают только HTTP(S), без логина и пароля в URL. Proxy сохраняется до `close`; смена proxy требует закрытия браузера. Открытия страниц и передача управления человеку используют текущий browser context, поэтому cookies и авторизация сохраняются в нём, но не переносятся автоматически в `curl` или другой HTTP-клиент.

Ограничения:

- `fill` отклоняет поля `type=password`; пароль вводит пользователь через `browser_handoff`. Пароли и одноразовые коды не запрашиваются в чате.
- Приём скачиваний отключён. `browser` не является инструментом скачивания файлов в workspace.
- `close` уничтожает текущий context и его авторизацию. Browser-сервис также завершает работу после более 30 минут бездействия; проверка выполняется раз в минуту.
- Браузер и ручной ввод не гарантируют снятие блокировки: сайт может вернуть `403` без CAPTCHA или возможности продолжить.

### `browser_handoff`

Передаёт открытую страницу пользователю для CAPTCHA, входа, одноразового кода или другого ручного действия. Показывает карточку браузера в чате.

| Параметр | Тип | Назначение |
|---|---|---|
| `reason` | string | Непустое описание необходимого действия, до 1000 символов |

Результат содержит идентификатор запроса и URL страницы. После вызова агент завершает ход. Пока браузером управляет человек, действия агента с ним заблокированы; агент не опрашивает браузер в ожидании результата. После возврата управления и сообщения пользователя работа продолжается через `browser` в том же context с сохранёнными cookies. Агент может читать содержимое авторизованной страницы, включая показанные на ней личные данные: вход в аккаунт предполагает доверие к агенту и среде этой сессии. Отмена закрывает браузер.

### `render_ui`

Показывает произвольный интерфейс A2UI прямо в ACP-чате: карточку, форму, макет или прототип.

| Параметр | Тип | Назначение |
|---|---|---|
| `components` | object[] | Плоский список компонентов; у каждого обязательны `id` и `component` |
| `dataModel` | object | Необязательная начальная модель данных для полей и привязок |

Допустимые значения `component`: `Text`, `Card`, `Column`, `Row`, `List`, `Divider`, `Image`, `Icon`, `Button`, `TextField`, `CheckBox`, `ChoicePicker`, `Slider`, `Tabs`.

Контракт интерфейса:

- Ровно один компонент имеет `id: "root"`.
- Props находятся непосредственно в объекте компонента, не в отдельном `props`.
- Дочерние компоненты задаются по ID: `children: ["id1", "id2"]`, у `Card` и `Button` — `child: "id"`.
- Привязка к модели данных имеет вид `{ "path": "/поле" }`.
- `Button` может задавать `action.event.name` и необязательный `action.event.context`. Действие пользователя возвращается агенту новым сообщением.

### `show_choice`

Показывает простую карточку с заголовком и вариантами выбора.

| Параметр | Тип | Назначение |
|---|---|---|
| `title` | string | Заголовок карточки |
| `options` | string[] | Варианты ответа |

### `save_note`

Показывает редактируемый черновик заметки. Сам вызов **не сохраняет заметку**: пользователь проверяет поля и нажимает «Сохранить», после чего Brigade выполняет сохранение без дополнительного действия агента.

| Параметр | Тип | Назначение |
|---|---|---|
| `title` | string | Заголовок заметки |
| `body` | string | Текст в Markdown |
| `topic` | string | Необязательное имя темы; пустое значение — «Общее» |
| `sub` | string | Необязательная подтема; пустое значение — «Общее» |
| `type` | string | Необязательный тип: `idea`, `decision`, `insight`, `todo`, `question`, `reference` |
| `tags` | string[] | Необязательные метки |

Параметра `layer` в этом инструменте нет. После показа черновика агент останавливается, не сохраняет его через API и не ожидает подтверждения для самостоятельного сохранения. Для сохранения нужна настроенная [личная память](memory.md).

### `publish_file`

Публикует файл workspace в виде карточки скачивания с защищённой ссылкой. Файл остаётся в workspace сессии.

| Параметр | Тип | Назначение |
|---|---|---|
| `path` | string | Относительный путь от workspace или абсолютный путь внутри него |
| `preview` | string | Необязательный путь к GLB/GLTF-превью, например для исходного STEP |

Оба пути должны указывать на существующие обычные файлы внутри workspace; переход через symlink за его пределы не допускается. Инструмент возвращает имя файла, URL и, при наличии, URL превью. Он не создаёт и не конвертирует 3D-модели: файл превью должен уже существовать.

Описание инструмента предписывает завершать ход карточкой без повторной ссылки или текста. Подробнее о показе файлов, моделей и интерфейсов: [Файлы, preview и A2UI](files-and-ui.md).

## Встроенные навыки

Навыки не добавляют самостоятельных MCP-инструментов. Это инструкции для агента, устанавливаемые в workspace сессии.

| Навык | Назначение | Условия установки |
|---|---|---|
| `preview` | Публикация HTTP dev server по шаблону `BRIGADE_PREVIEW_URL_TEMPLATE`; регистрация порта через `AgentBridgeService/RegisterPreview` добавляет ссылку в UI | Claude и Codex, CLI и ACP, при включённом preview |
| `note` | Один черновик через `save_note`; отдельный сценарий сохранения итогов сессии и атомарных фактов через `AgentBridgeService/CreateMemoryNote` | Те же условия, что у `preview`; установка не зависит от настройки памяти |
| `brigade-ui` | Поиск deferred-инструментов `render_ui` и `show_choice` для интерфейсов внутри чата | Только Codex ACP, независимо от preview |
| `brigade-files` | Использование `publish_file` для скачивания и 3D-превью; подготовка GLB доступными средствами проекта | Только Codex ACP, независимо от preview |

Для Claude `preview` и `note` входят в локальный плагин `brigade` и доступны как `/brigade:preview` и `/brigade:note`. Для Codex навыки устанавливаются в `.agents/skills/` без Claude marketplace. В Codex MCP-инструменты могут быть отложены до поиска инструментов; навыки `brigade-ui` и `brigade-files` сообщают агенту об их наличии.

Навык `preview` использует порт работающего HTTP-сервера, имя сервиса и идентификатор сессии. В Docker сервер должен слушать `0.0.0.0`. Регистрация возвращает preview URL, но не запускает сервер.

В сценарии итогов сессии `note` описывает одну заметку слоя `episodic` и несколько фактов слоя `semantic`. Прямой API принимает `sessionId`, `title`, `body`, `type`, `tags`, `layer`, `topic`, `sub` и возвращает ID заметки и commit SHA. Это отдельный сценарий, не параметры карточки `save_note`. При ненастроенном репозитории памяти сохранение возвращает `failed_precondition`.

Оба навыка используют `BRIGADE_API_URL` и `BRIGADE_PREVIEW_TOKEN` для обращений к API. `RegisterPreview` и `CreateMemoryNote` — методы ConnectRPC, а не дополнительные MCP-инструменты.

## Browser-инструкции и границы набора

Отдельного встроенного browser-skill нет. Brigade добавляет browser-инструкцию в system prompt ACP-сессии: использовать исходный URL и тот же явно настроенный proxy, передавать ручной ввод пользователю, не решать CAPTCHA автоматически, не опрашивать браузер во время передачи управления и продолжать в том же context. Эта инструкция не устанавливает браузер и не гарантирует доступ к сайту.

Встроенный набор Brigade не включает:

- Собственные инструменты, skills и slash-команды Claude/Codex. Их состав зависит от агента и его версии.
- MCP-серверы, выбранные пользователем в настройках сессии. Их инструменты определяются конфигурацией этих серверов.
- Инструменты и инструкции установленных [плагинов](plugins.md). Experience-плагин выбирается отдельно, требует ACP и поддержки текущей среды.
- Навыки из пользовательского workspace или персональной конфигурации агента.

Локальный Claude-плагин `brigade` с навыками `preview` и `note` — часть встроенной поставки, а не выбранный пользователем experience-плагин. Внутренние действия ручного браузера, например получение кадра или возврат управления, также не являются отдельными MCP-инструментами агента.

Диагностика среды и сессий: [Решение проблем](../reference/troubleshooting.md).
