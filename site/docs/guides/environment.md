# Среда агента

Режим исполнения задаётся для всего инстанса.

## Local

Агент запускается процессом на машине Brigade, наследует её `PATH` и видит локальные инструменты. В Brigade.app этот режим удобен для персональной работы без контейнеров.

## Docker

ACP-сессия получает отдельный контейнер. CLI-сессии одного пользователя используют общий долгоживущий контейнер. Пользовательские home разделены, а workspace сохраняется на хосте.

На сервере Local/Docker задаётся `mode` в конфигурации и показывается в UI без переключателя. В Brigade.app режим и Docker context можно менять в **Настройки → Среда агента**.

## Пользовательские образы

Пользователь задаёт скрипт установки, а Brigade собирает дополнительный слой поверх базового образа инстанса. Добавить произвольную ссылку на образ нельзя. Базу выбирает администратор через `agent_image`.

### Собрать окружение из скрипта

1. Откройте **Настройки → Среда агента** в режиме Docker. В Brigade.app выберите работающий Docker context. Если приложение требует перезапуска после изменения настроек, сначала перезапустите его: до этого сборка недоступна.
2. Заполните обязательное поле **Название**, например `python-tools`. Используйте от 1 до 40 символов из `a-z`, `0-9`, `.`, `_`, `-`; первый символ — латинская строчная буква или цифра.
3. В поле **Скрипт установки** укажите команды установки инструментов. Например, для базового образа Brigade:

   ```sh
   apt-get update
   apt-get install -y --no-install-recommends ffmpeg
   rm -rf /var/lib/apt/lists/*
   ```

   Не оставляйте скрипт пустым и не превышайте 64 KiB. Не добавляйте токены, пароли и другие секреты: секреты из vault в сборку не передаются.
4. Устанавливайте инструменты в `/usr/local` или `/opt`, а не в home или workspace: при запуске сессии смонтированные каталоги могут скрыть установленные там файлы. Размещайте исполняемые файлы в доступном через `PATH` каталоге, например `/usr/local/bin`: `export PATH=…` в скрипте не сохраняется для будущих сессий.
5. Нажмите **Собрать** и следите за состоянием и логом. Для повторной сборки без кеша используйте **Пересобрать без кеша**, для остановки — **Отменить**.
6. После успешной сборки выберите образ по указанному названию при создании сессии: UI отображает `name`, а backend хранит постоянный тег `brigade-build:<userID>.<name>`. Чтобы обновить окружение, повторите сборку с тем же названием. Тег обновится только после успешной сборки, проверки образа (`CheckImage`) и квоты; при ошибке прежний рабочий тег сохранится. Существующие сессии остаются без изменений.

После обновления страницы продолжайте следить за сохранённым состоянием сборки. Если сервер перезапустился во время сборки, запустите её заново: прерванные сборки автоматически не возобновляются.

Параметры, ограничения и требования к доверию пользователей описаны в [справочнике конфигурации](../reference/configuration.md#сборка-окружения).
