# Файлы, preview и A2UI

## Файлы и изображения

Агент может опубликовать файл из workspace через встроенный MCP Brigade. В чате появится карточка с авторизованной ссылкой; изображения показываются inline и пересылаются в Telegram. Повторная публикация того же пути помечает старые карточки как outdated.

GLB/GLTF и поддерживаемые CAD-файлы можно вращать и смотреть прямо в чате. Файл остаётся в workspace сессии и отдаётся через защищённый endpoint, а не через прямой путь файловой системы.

## Dev preview

Встроенный L7 proxy публикует dev-сервер агента. Ссылки появляются в меню **Ссылки**. Доступны два режима:

- `subdomain`: `{sessionId}-{port}.example.com`, нужен wildcard DNS;
- `cookie`: один preview-host, выбор сессии и порта хранится в cookie.

Для публичного production URL настройте HTTPS и параметры `preview` в конфигурации инстанса.

## A2UI

Встроенный MCP умеет рендерить интерактивные формы и карточки прямо в ACP-чате. Компонент остаётся последним активным элементом ответа; действия отправляют структурированные данные обратно агенту. Простые варианты выбора и карточки заметок используют тот же механизм.
