# Подключения агентов

В **Настройки → Агенты** можно добавить несколько именованных подключений Claude Code и Codex, в том числе несколько учётных записей одного агента. При создании сессии или Telegram-бота выбирается конкретное подключение.

Нажмите **Добавить**, задайте понятное название и выберите агента. Тип агента и способ авторизации после сохранения не меняются; для другого варианта создайте новое подключение.

## Claude Code

Выберите **Claude Code** и сохраните subscription token. Его можно получить командой:

```bash
claude setup-token
```

## Codex

Выберите **Codex** и один способ авторизации:

- **ChatGPT Plus** — нажмите **Подключить ChatGPT**, откройте выданную ссылку и введите одноразовый код. После успешного login подключение сохранится автоматически. Вместо этого можно импортировать содержимое `~/.codex/auth.json` с доверенной машины;
- **OpenAI API Key** — сохраните API key.

Секрет каждого подключения шифруется на сервере и не возвращается через API. Сохранение формы с пустым полем секрета оставляет прежнее значение.

{% note warning %}

Перед удалением подключения переведите на другое подключение связанные Telegram-боты и завершите нужные сессии. Удалённые credentials больше нельзя использовать для запуска или перезагрузки агента.

{% endnote %}

## Режим доступа

ACP предоставляет режимы агента, например read-only, Agent и Agent (full access), если адаптер агента их поддерживает. Изменение применяется к текущей сессии после подтверждения в UI. Full access снимает запросы разрешений агента, поэтому используйте его только в доверенной среде.
