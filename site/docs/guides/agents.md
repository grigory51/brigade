# Claude Code и Codex

Агент выбирается отдельно для каждой сессии.

## Claude Code

В **Настройки → Claude Code** сохраните subscription token. Для CLI-сессии также можно пройти интерактивный login в терминале. ACP требует готовой авторизации до запуска.

## Codex

В **Настройки → Codex** выберите один способ:

- **ChatGPT Plus** — запустите device login, откройте выданную ссылку и введите одноразовый код;
- **API Key** — сохраните ключ OpenAI API.

Если настроены оба профиля, выберите профиль по умолчанию. При создании сессии его можно изменить.

## Режим доступа

ACP предоставляет режимы агента, например read-only, Agent и Agent (full access), если адаптер агента их поддерживает. Изменение применяется к текущей сессии после подтверждения в UI. Full access снимает запросы разрешений агента, поэтому используйте его только в доверенной среде.
