# Память и архив

Память — один приватный git-репозиторий на пользователя, общий для всех агентов.

## Настройка

1. Создайте приватный пустой репозиторий.
2. Откройте **Настройки → SSH-ключ** и добавьте публичный ключ Brigade в репозиторий с правом записи.
3. В **Настройки → Память** укажите `git@` remote и ветку.
4. Сохраните и запустите проверку/обновление памяти.

Для `git@` используется SSH-ключ агента — отдельный ключ памяти не нужен. Приватный ключ хранится зашифрованным в базе, а git и сессии получают только in-memory ssh-agent socket.

## Заметки

Агент читает память в начале сессии и может показать карточку новой заметки через `/note`. Сохранение карточки выполняет браузер от имени пользователя. В разделе **Заметки** можно искать, редактировать и удалять Markdown-записи.

## Архив

Архивирование коммитит метаданные и полную историю сессии в каталог `archive/`. Архив остаётся доступным как read-only чат со ссылками. Удаление архива удаляет его из репозитория.
