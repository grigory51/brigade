# Быстрый старт

Рекомендуемый вариант для сервера — Docker. Нужны Linux amd64, работающий Docker Engine и `curl`.

## 1. Установите Brigade

Перед запуском можно [прочитать install.sh на GitHub](https://github.com/grigory51/brigade/blob/main/site/install.sh).

```bash
curl -fsSL https://grigory51.github.io/brigade/install.sh | sudo sh
```

Скрипт создаст `/srv/brigade`, сгенерирует JWT-секрет и пароль администратора, запустит сервер и напечатает данные для входа. Откройте `http://<server>:8080`.

{% note warning %}

Docker socket даёт Brigade возможность создавать контейнеры на хосте. Не открывайте инстанс недоверенным пользователям и не публикуйте его без аутентификации и защищённого соединения.

{% endnote %}

## 2. Подключите агента

Откройте **Настройки → Агенты**, нажмите **Добавить**, задайте название подключения и выберите:

- **Claude Code** — сохраните subscription token из `claude setup-token`;
- **Codex** — выберите ChatGPT Plus и пройдите device login либо выберите API Key.

Можно добавить несколько подключений одного типа, например личный и рабочий Codex. Секреты хранятся зашифрованными на сервере и не возвращаются в браузер после сохранения.

## 3. Создайте сессию

Нажмите **Новая сессия**, затем выберите:

1. настроенное подключение агента;
2. **ACP** для чата либо **CLI** для полноценного терминала;
3. при необходимости MCP-серверы, профиль ответа и пользовательский Docker-образ.

Для первого запуска выберите **ACP** и базовый образ. После создания отправьте задачу в поле ввода. Сессия продолжит работать при закрытом браузере.
