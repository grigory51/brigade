# Brigade

Brigade — self-hosted рабочее пространство для coding agents. Оно запускает Claude Code и Codex на вашем компьютере или сервере и сохраняет сессии, даже когда браузер закрыт.

В одной установке доступны:

- терминальные CLI-сессии и структурированный ACP-чат;
- локальный запуск или изолированные Docker-контейнеры;
- персональные MCP-серверы с защищёнными секретами;
- Telegram-боты, память в git, уведомления и preview dev-серверов;
- интерактивные A2UI-карточки, файлы, изображения и просмотр 3D/CAD.

{% note warning %}

Проект развивается быстро. Размещайте сервер за VPN или в доверенной сети, смените стандартные учётные данные и `jwt.secret` до публикации в интернет.

{% endnote %}
