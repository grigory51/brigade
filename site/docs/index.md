# Brigade

Brigade — self-hosted рабочее пространство для ACP-совместимых агентов. Оно запускает агентов на вашем компьютере или сервере и сохраняет сессии, даже когда браузер закрыт. Архитектура расширяема: сейчас реализованы подключения Claude Code и Codex; поддержка других агентов добавляется через интеграцию с ACP.

В одной установке доступны:

- терминальные CLI-сессии и структурированный ACP-чат;
- локальный запуск или изолированные Docker-контейнеры;
- персональные MCP-серверы с защищёнными секретами;
- Telegram-боты, память в git, уведомления и preview dev-серверов;
- интерактивные A2UI-карточки, файлы, изображения и просмотр 3D/CAD.

Для предметных задач установите [MCP App](guides/plugins.md): приложение получает
собственную рабочую область сессии. Первый плагин — [CAD](guides/cad.md) с build123d,
редактируемыми параметрами, проверками геометрии, ревизиями и экспортом STEP.

[Desktop-приложение Brigade.app](installation/desktop.md) подключается и к удалённым инстансам,
пробрасывает порты и монтирует workspace через FUSE-T. На сервере можно настроить
[вход через OIDC](guides/authentication.md), обязательную роль и отключить парольный вход.

{% note warning %}

Проект развивается быстро. Размещайте сервер за VPN или в доверенной сети, смените стандартные учётные данные и `jwt.secret` до публикации в интернет.

{% endnote %}
