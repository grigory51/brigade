Bring your tools.
Add your own MCP servers and select them per session. Tokens and other secrets stay encrypted on the server; environment variables and headers reference them when needed.
Set the tone.
Use a response profile for concise answers, detailed explanations or your own instructions. Change it as the work changes, without rewriting your messages.
Keep what you learn.
Notes and archived conversations live in your private git repository, shared across your agents. Archive preserves a read-only chat snapshot; it is not a workspace backup.

Give it a home.

One Go binary serves Brigade and its web interface. Run agents as local processes or in Docker, with a custom image when your tools need one.

Linux amd64 · Docker installed
curl -fsSL https://grigory51.github.io/brigade/install.sh | sudo sh

The installer generates credentials and starts Brigade on port 8080. It grants Brigade access to the Docker socket: use a trusted host and HTTPS or a VPN. Read the installer.
